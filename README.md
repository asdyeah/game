# Угадай флаг

Онлайн-викторина: угадай страну по флагу. 20 вопросов, игра в одиночку или с друзьями по коду лобби.

- Регистрация и вход (пароли хранятся в виде хэшей)
- База данных SQLite (файл `data.db` создаётся автоматически)
- Лобби с кодом подключения, кнопка «Начать игру» только у создателя
- По итогам места 1-2-3 по количеству верных ответов и скорости
- История всех игр в профиле

## Запуск

```
npm install
npm start
```

Открой http://localhost:3000

## Важно про хостинг

GitHub Pages не умеет запускать серверы и базы данных. Чтобы сайт был доступен в интернете,
задеплой репозиторий на Render / Railway / Fly.io (команда запуска: `npm start`).
Для сохранности базы подключи постоянный диск и укажи переменную `DB_PATH`.
